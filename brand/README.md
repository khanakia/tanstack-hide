# tanstack-hide brand

The visual identity for tanstack-hide. Everything here is generated by `gen-brand.mjs` from `brand.json`; edit those two, never the outputs.

## The mark

A round island badge (sunset sky, sea, palm island) with a white slash: "the TanStack corner badge, hidden". It echoes the palette of the TanStack devtools trigger without copying the TanStack logo, which is a trademark of its owners.

The slash runs top-left to bottom-right on purpose: the extension draws its status dot in the icon's top-right corner, and the slash must never sit under it.

## Type

Display: Space Grotesk. Sans: Inter. Mono: JetBrains Mono. All are open source (OFL). The wordmark, lockups and OG cards name the display font with a system fallback, so a machine without Space Grotesk renders them in the fallback font; the PNGs in `png/` were rendered on a machine that had the fallback, not necessarily Space Grotesk.

## Don'ts

- Don't recolour outside the palette; add a variant to `gen-brand.mjs` instead.
- Don't stretch or rotate the mark; the slash angle is intentional (see above).
- Don't add shadows or bevels; the mark is flat.
- Don't use the full-detail badge below about 24 px; use `favicon.svg`.
- Keep clear space of at least 25% of the badge width around it.
- Don't put the TanStack logo or the word "TANSTACK" inside the mark.

## Regenerate

```sh
task brand          # from the repo root: brand kit + extension icons
task -d brand all   # brand kit only (SVG + tokens + PNG)
```

Needs Node, `rsvg-convert` and ImageMagick (`magick`).
