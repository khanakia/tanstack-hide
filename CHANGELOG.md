# Changelog

All notable changes to **tanstack-hide** are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Brand kit in `brand/`: icon variants, favicon, wordmark, lockups, OG social covers, Chrome Web Store promo tile and design tokens, generated by `brand/gen-brand.mjs` (`task brand`).
- README screenshots and a full usage guide; `task screenshots` regenerates the screenshots from a test run.
- Community files: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, issue and pull request templates, `llms.txt`.

## [1.3.0] - 2026-10-11

### Changed

- New logo: a round sunset island badge with a slash.

### Fixed

- A text badge ("HID" / "SHOW") left over from 1.1 could cover the status dot after updating; it is now cleared.

## [1.2.0] - 2026-10-11

### Added

- Help popover (`?`) on every control in the popup.
- Extension icon and logo.

### Changed

- The toolbar status is a coloured dot on the icon instead of a text badge.

### Fixed

- The toolbar status could show the previous state when two changes landed quickly, or stay blank after a page load.

## [1.1.0] - 2026-10-11

### Added

- Popup with a master switch, a global "Hide on all sites" default and per-site rules (Global / Always hide / Always show).
- Site rules list with removal.
- Live status of the current tab in the popup and on the toolbar icon.
- Alt+Shift+H shortcut to flip the current site.
- Settings synced with Chrome sync.

## [1.0.0] - 2026-10-11

### Added

- Hide the floating TanStack Devtools trigger button on every page, leaving the devtools panel and its hotkey working.
