## [0.1.0] - 2026-10-11

First release.

### Added

- Hide the floating TanStack Devtools trigger button on every page, leaving the devtools panel and its hotkey working.
- Popup with a master switch, a global "Hide on all sites" default and per-site rules (Global / Always hide / Always show), plus a site rules list with removal.
- Live status of the current tab in the popup, and a coloured status dot on the toolbar icon.
- Help popover (`?`) on every control in the popup.
- Alt+Shift+H shortcut to flip the current site.
- Settings synced with Chrome sync.
- Logo and brand kit in `brand/` (icon variants, favicon, wordmark, lockups, social covers, Chrome Web Store promo tile, design tokens), generated by `brand/gen-brand.mjs` (`task brand`).
- README guide with screenshots; `task screenshots` regenerates them from a test run.
- Release packages: `task release` builds a versioned zip, a signed `.crx` (extension ID `bofgjoofhcigpodhkppgnbmhjdcniinj`) and `SHA256SUMS.txt`.
- Community files: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, issue and pull request templates, `llms.txt`.
